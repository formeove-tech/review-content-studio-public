# 리뷰 콘텐츠 스튜디오 (공개판)

**배달앱 손님 리뷰 한 줄이 인스타 캐러셀 · 릴스 영상 · 새소식 문구가 됩니다.**
동네 식당 사장님이 AI(Claude)와 대화하며 만들었습니다. 코드는 직접 쓰지 않았고, 하고 싶은 일을 말로 했습니다.

> 🧪 **바로 눌러 보기 (로그인 없음, 가상 데이터)** → https://review-content-studio-demo.vercel.app
> 가상 가게·가상 리뷰·가상 그림만 들어 있습니다. 실제 가게·손님 정보는 이 저장소 어디에도 없습니다.

## 어떤 문제를 푸나요

장사하느라 손님 리뷰를 읽을 시간은 있어도, 그 리뷰로 **홍보 글·영상을 만들 시간**은 없습니다.
리뷰 한 줄(“국물이 진해서 해장에 딱이었어요”)은 어떤 광고 문구보다 믿음이 가는데, 그냥 흘려보내고 있었습니다.

## 데모에서 3분 안에 해 볼 것

| 순서 | 어디서 | 누르는 것 | 나오는 것 |
|---|---|---|---|
| 1 | 첫 화면 | 사진(📷)이 있는 리뷰 2~4개의 **묶기** 체크 → 아래 **선택한 리뷰로 콘텐츠 만들기** | 여러 손님의 말을 골고루 인용한 캐러셀·릴스·새소식 |
| 2 | **인스타 캐러셀** 탭 | **이미지 만들기** → 크기(인스타 4:5 / 스레드 1:1)·스타일(임팩트·담백·감성·친근) 바꾸기 | 사진 위에 문구가 얹힌 슬라이드 이미지 (저장·카톡 보내기) |
| 3 | **릴스/쇼츠 대본** 탭 | **영상 만들기** | 사진이 천천히 움직이며 자막이 바뀌는 세로 영상(MP4, 폰·PC 브라우저가 직접 만듭니다) |

만든 것은 저장되지 않고 새로고침하면 처음 상태입니다(화면마다 따로 도는 서버라 서로 기억을 나누지 않아요).
데모에서는 AI 대신 **미리 정한 틀**로 만듭니다(비용·남용 걱정 없음). 진짜 앱에서는 Claude가 리뷰마다 새로 씁니다.

## 진짜 앱에는 더 있습니다

- **리뷰 자동 수집**: 배민 사장님 사이트·쿠팡이츠 사장님 사이트·네이버 플레이스에서, 사장님 노트북의 크롬으로 읽어 옵니다(읽기만 합니다). 이미 저장한 리뷰는 건너뛰고 새 리뷰만 받습니다.
- **주간 베스트 Top 5** · **리뷰 묶음 콘텐츠** · **요즘 뜨는 소재 찾기**(AI 웹 검색) · **훅 카피 규칙 13가지** · **디자인 스타일 4종** · **가게 로고** · **카톡으로 보내기**
- **리뷰에 없는 말은 지어내지 않습니다.** 손님 이름은 가려서 씁니다.

## 우리 가게에 쓰려면 (개발을 몰라도 AI에게 부탁하면 됩니다)

1. 이 저장소를 내 컴퓨터에 받습니다. (`git clone` 또는 ZIP)
2. `.env.example`을 `.env.local`로 복사하고 AI 키(`ANTHROPIC_API_KEY`)를 넣습니다. **키는 절대 올리지 않습니다** (`.env*`는 자동으로 제외됩니다).
3. `npm install --legacy-peer-deps` 후 `npm run dev` → http://localhost:3400
4. 설정 화면에서 가게 이름·대표 메뉴를 넣고, 대시보드의 수집 버튼을 누릅니다.

데모 모드로 켜 보려면 `npm run dev:demo` (http://localhost:3402).

## 이 저장소에서 지킨 약속

- 실제 손님 사진·실제 가게 로고·실제 매출은 올리지 않았습니다. 데모의 음식 그림은 코드로 그린 가상 그림입니다 (`scripts/make-demo-assets.mjs`).
- 손님이 올린 리뷰 사진은 그 손님의 것입니다. 홍보에 쓰기 전에 답글로 양해를 구하는 것을 권합니다.
- `.env`·키·실제 수집 자료(`data/`)는 저장소에 없습니다. 올리기 전에 검사 스크립트로 실제 정보가 섞이지 않았는지 확인했습니다.
